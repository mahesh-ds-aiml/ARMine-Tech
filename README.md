# AR Mine - Augmented Reality for Industrial Safety

AR Mine explores how Augmented Reality can improve safety awareness, training, equipment understanding, and workplace guidance across mining and manufacturing environments.

## 📁 Project Structure

```text
/
├── public/
│   └── assets/
├── src/
│   ├── components/
│   ├── layouts/
│   ├── pages/
│   ├── scripts/
│   └── styles/
├── .gitignore
├── astro.config.mjs
├── package.json
└── README.md
```

## 🛠️ Commands

| Command | Action |
| :--- | :--- |
| `npm install` | Installs dependencies |
| `npm run dev` | Starts local dev server at `localhost:4321` |
| `npm run build` | Build your production site to `./dist/` |
| `npm run preview` | Preview your build locally |
